# KVEE-CSE
Konvencionalni viri električne energije-Vaje/Conventional sources of energy-Exercises

# Delovni zvezek s prilogami Python code in preglednicami
Namen delovnega zvezka je, da študentom služi kot predloga in  v pomoč pri izvajanju vaj pri predmetu Konvencionalni viri električne energije, ki se izvaja na Fakulteti za elektrotehniko, Univerze v Ljubljani. Vsebina delovnega gradiva se prekriva s predavanji in je za študente priporočljivo, da pred pričetkom reševanja posameznih sklopov prelistajo in osvežijo gradivo s predavanj.
Ker je predmet dvojezičen,  angleški študenti uporabljajo  modro označena besedila, slovenski študenti pa črna besedila. 


# Workbook with Python code and spreadsheets as attachments
The purpose of the workbook is to serve as a template and aid for students in completing exercises in the course Conventional Sources of  Energy, which is taught at the Faculty of Electrical Engineering, University of Ljubljana. The content of the working material overlaps with the lectures and it is recommended that students review and refresh the material from the lectures before starting to work on the individual units.
As the course is bilingual, the English students should refer to the blue marked texts, and Slovene students to the black ones.
